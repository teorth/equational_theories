## Vampire data

The vampire json describes results of vampire. It comprises two dictionaries:
methods and values. The methods are from method_id to solver configurations.
Values map a pair of equation ids x, y to a triple describing value, time,
method_id. The pair is concerned with the implication x=>y. The value comes
from the enum below. I.e. 0 means that the implication was refuted, 1 means
that the implication was proven.

````
class Res(Enum):
    """Possible result for single implication."""

    IMPL_FALSE = 0
    IMPL_TRUE = 1
    IMPL_UNKNOWN = 2
````

## Higman-Neumann data

The JSON file `Higman-Neumann.json` lists 213 equation ids, the
corresponding law, the id of a "parent law" which specializes to this
law, and the class: 179 "HN-equivalent" equations whose models are
groups equipped with division, 21 "finite-equivalent" equations whose
finite models have the same property, and 13 "unknown-candidate"
equations for which it is unknown whether they have finite or infinite
non-group models. See `Higman-Neumann.md` for a detailed description.

## `full_entries.json`

`full_entries.json` lists every declaration tagged `@[equational_result]` that is
part of the general graph (e.g. it does not include finite-only implications.) It can
be regenerated by running:
````sh
lake build equational_theories
lake exe extract_implications raw --full-entries | python3 -m json.tool --indent 1 > data/full_entries.json
````

The file is a list of JSON entries such as:
````
{
 "filename": "equational_theories/Subgraph.lean",
 "line": 23,
 "name": "Subgraph.Equation2_implies_Equation3",
 "proven": true,
 "variant": {
  "implication": {
   "finite": false,
   "lhs": "Equation2",
   "rhs": "Equation3"
  }
 }
}
````

where `"proven"` is `true` or `false` and `"variant"` is one of

- `{"implication": {"finite": false, "lhs": "EquationN", "rhs": "EquationM"}}`:
  every (finite?) magma satisfying law N satisfies law M.
- `{"facts": {"finite": false, "refuted": [...], "satisfied": [...]}}`:
  there is a (finite?) magma satisfying every law in `satisfied` and not satisfying
  the laws in `refuted`.
- `{"unconditional": "EquationN"}`: law N holds in every magma.

`"proven": false` marks a statement declared with `conjecture` rather than
`theorem`. It has no proof and is only used for bookkeeping purposes in the
project's frontends.
