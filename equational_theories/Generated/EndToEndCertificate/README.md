# Regenerating the certificate

Everything in this directory is generated by `src/generate.py`. It is the untrusted
certificate of the end-to-end proof, see `equational_theories/EndToEnd/README.md`.
To regenerate the certificate, run:
```sh
lake build equational_theories
lake exe extract_implications raw --full-entries > /tmp/entries.json
python3 equational_theories/Generated/EndToEndCertificate/src/generate.py /tmp/entries.json
```

The tables live in `json/`, and regenerating them does not invalidate the current `.olean`s.
If updating the certiicate, you must force this directories files to re-build.

The `.lean` files in this directory are just thin wrappers around meta-code in
`equational_theories/EndToEnd/Load.lean` that loads the associated JSON file and
generates an appropriate term using it.

## Provenance

The entirety of the lean code in this directory is auto-generated. The generation script under
`src/` is entirely written by AI. This README is human-written.
